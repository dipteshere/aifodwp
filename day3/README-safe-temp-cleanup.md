# DWP Safe Temp Cleanup Script (PowerShell 5.1)

This document explains how to use `dwp-temp-cleanup.ps1` in `day3`.

## Script Location

- `day3/dwp-temp-cleanup.ps1`

## What The Script Does

The script safely cleans temporary files on Windows endpoints and supports rollback.

- Dry run mode lists files that would be removed without changing anything.
- Live cleanup mode moves eligible files into a rollback store, then removes them from temp locations.
- Rollback mode restores files from a selected manifest file.

## Key Safety Behaviors

- Per-file try/catch handling to avoid full-script failure.
- Locked files are skipped and logged.
- Every action is logged to a timestamped log file.
- Summary is printed at the end of each run.
- Idempotent behavior for repeated cleanup and rollback runs.

## Parameters And Options

### Cleanup Parameter Set

- `-DryRun`
  - Optional switch.
  - Shows which files would be deleted.
  - No file move or delete operation occurs.

- `-OlderThanDays <int>`
  - Optional integer.
  - Default is `0`.
  - Targets files with `LastWriteTime` older than the computed cutoff.

- `-TargetPaths <string[]>`
  - Optional string array.
  - Defaults to:
    - `%TEMP%`
    - `%WINDIR%\Temp`
  - Use this if you want to scope cleanup to specific folders.

- `-StateRoot <string>`
  - Optional path.
  - Default is `C:\ProgramData\DWPTempCleanup`.
  - Stores logs and rollback backup data.

### Rollback Parameter Set

- `-Rollback`
  - Required switch for rollback mode.
  - Tells the script to restore files, not clean them.

- `-ManifestPath <string>`
  - Required in rollback mode.
  - Path to manifest CSV generated by a previous live cleanup run.

- `-StateRoot <string>`
  - Optional path.
  - Same meaning as cleanup mode.

## Output Paths

- Logs:
  - `C:\ProgramData\DWPTempCleanup\Logs\temp_cleanup_yyyyMMdd_HHmmss.log`

- Rollback backup and manifest (live cleanup only):
  - `C:\ProgramData\DWPTempCleanup\Backups\run_yyyyMMdd_HHmmss\manifest.csv`

## Usage Examples

### 1) Dry Run (Recommended First)

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\day3\dwp-temp-cleanup.ps1 -DryRun -OlderThanDays 7
```

### 2) Live Cleanup

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\day3\dwp-temp-cleanup.ps1 -OlderThanDays 7
```

### 3) Cleanup With Custom Target Paths

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\day3\dwp-temp-cleanup.ps1 -OlderThanDays 3 -TargetPaths "C:\Windows\Temp","C:\Users\Public\Temp"
```

### 4) Rollback Using A Manifest

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\day3\dwp-temp-cleanup.ps1 -Rollback -ManifestPath "C:\ProgramData\DWPTempCleanup\Backups\run_20260805_113000\manifest.csv"
```

## Idempotency Notes

- Cleanup re-run:
  - Already moved files are no longer in target temp locations, so they are not re-processed.

- Rollback re-run:
  - If the destination file already exists, restoration is skipped and logged.
  - If the backup artifact is missing, it is skipped and logged.

## Operational Guidance

- Run dry run first before live cleanup.
- Review the generated log file for locked-file skips and errors.
- Keep manifest files until you are sure rollback is no longer needed.
