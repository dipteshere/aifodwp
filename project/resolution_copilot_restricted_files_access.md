# Resolution Document: Potential Restricted File Access via Copilot

## Issue
A paralegal reported Copilot surfaced a client matter they believe they should not have access to.

## What Is Confirmed
- Single user report exists.
- Report is not yet technically validated.
- Windows 11 update has occurred.
- New application deployment occurred Friday afternoon.

## Resolution Goal
Determine whether unauthorized access occurred and contain any confidentiality risk immediately.

## Immediate Containment
1. Treat as potential security/privacy incident until disproven.
2. Preserve evidence immediately:
- user prompt text
- Copilot response snippet
- timestamp
- user/device identity
- item/matter identifier
3. Escalate to security/governance and legal/compliance response owners per policy.

## Resolution Steps
1. Validate access behavior:
- Test direct access to the same matter outside Copilot.
- Verify effective permissions for reporting user.
- Review historical permission changes for that matter.
2. Validate platform and indexing factors:
- Confirm search/indexing scope and connector mappings (to confirm owners/tools).
- Check whether metadata/classification could have caused misinterpretation.
3. Scope expansion check:
- Determine whether other users can reproduce similar exposure.
4. If unauthorized access is confirmed:
- Execute incident response containment plan (to confirm playbook ID).
- Apply access correction and governance controls.

## Validation Criteria
- Access model verified as expected for reported matter.
- No unauthorized visibility reproduced for reporting user.
- Broader sampling does not show additional unauthorized exposure.

## Residual Risk
- Until validation completes, confidentiality and compliance risk remains active.

- No confirmed unauthorized exposure statement should be made until validation is complete.
