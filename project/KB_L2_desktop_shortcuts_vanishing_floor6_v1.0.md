# Scope
Use this article when one or more Floor 6 users report missing desktop shortcuts after recent Windows or application changes.

# Known Context
- Windows 11 update has occurred.
- New application deployment occurred Friday afternoon.
- Issue may be isolated or part of broader profile or desktop behavior.

# Procedure
1. Confirm scope.
Expected result: You know whether the issue affects one user or multiple users.

2. Provide workaround.
Expected result: User can launch required apps from Start, Search, or known path.

3. Verify shortcut locations.
Expected result: Shortcut state is identified as deleted, hidden, or moved.
Check:
- current user desktop path
- public desktop path

4. Review profile and policy behavior.
Expected result: Any recent change affecting desktop items is identified.

5. Review redirection or sync state if used.
Expected result: OneDrive or profile redirection issues are confirmed or ruled out.

6. Restore shortcuts.
Expected result: Required shortcuts are visible and launch correctly.

# Verification
1. Shortcuts are visible.
2. Shortcuts launch expected targets.
3. Shortcuts remain present after sign-out and sign-in.

# Escalation
Escalate if the same shortcut set disappears for multiple users or returns only temporarily.
