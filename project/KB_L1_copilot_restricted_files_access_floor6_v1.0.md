- Version: 1.0
- Date: 2026-08-14
- Source Runbook: runbook_copilot_restricted_files_access_floor6_v1.0

If Copilot shows a matter or file you do not think you should see, stop and report it immediately.

1. Do not keep opening or sharing the item.
Expected result: Possible exposure is limited while the issue is checked.

2. Take a screenshot if allowed by policy.
Expected result: Support has evidence of what was shown.

3. Report the issue to support right away.
Provide:
- what you asked Copilot
- what it showed
- the time it happened
- your device name

What IT and security will do:
- preserve the details of the event
- check whether access was correct
- review permissions and records
- keep you updated while validation is in progress
