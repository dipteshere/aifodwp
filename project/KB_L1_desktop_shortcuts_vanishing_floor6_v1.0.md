If desktop shortcuts disappear, your apps may still be available.

1. Open the app from the Start menu or Search.
Expected result: You can continue working while the shortcut issue is checked.

2. Restart your device once.
Expected result: If the desktop did not load correctly, the shortcuts may return.

3. Contact support if shortcuts are still missing.
Provide:
- your device name
- which shortcuts are missing
- whether the app still opens from Start or Search

What IT will do:
- check whether the issue affects only you or more users
- check desktop and public shortcut locations
- review recent profile or policy changes
- restore shortcuts from the approved source if needed
